# 컴파일 타임과 런타임
## 컴파일 타임
- 사람이 작성한 소스 코드가 기계어로 번역되는 단계
- 자바의 경우, 소스 코드 컴파일의 결과로 **바이트 코드(byte code)** 생성
### 수행되는 작업
- 구문 분석: 코드의 문법적 오류(세미콜론 누락 등) 검사
- 의미 분석: 코드의 논리적 오류 확인
  - 변수의 타입, 반환 타입 불일치
  - 메서드 호출 유효성 등
- 코드 최적화: 일부 컴파일러는 프로그램 성능 향상 목적으로 소스 코드를 최적화
  - 불필요한 연산 제거
  - 상수값 미리 계산
## 런타임
- 컴파일된 바이트 코드가 JVM에 의해 실행되는 단계
- 바이트 코드가 실행되는 과정은 아래와 같음
1. JVM이 메모리로 바이트 코드 로드
2. 바이트 코드 해석한 뒤 명령어 순차적으로 실행
   - 실행 도중 런타임 에러(예: `NullPointerException`) 발생 가능
### 런타임에 실행되는 작업
- 객체를 메모리에 동적 할당
- 연산 수행
- 운영체제 및 외부 리소스와 상호작용
