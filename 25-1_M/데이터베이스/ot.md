# OT 내용 정리
## Oracle Live SQL
- 로컬 DB: 설치한 시스템과 충돌할 가능성 존재
- 차라리 클라우드 형태로 이용하는 것이 편하지 않을까?
- 그리고 오라클 DB는 규모가 큰 회사에서 많이 사용한다고 함

## DB 용어 정리
- 스키마: DB 구조
- 테이블: DB의 저장 단위(아마 관계형 DB이지 않을까..). 한 DB에 여러 테이블들이 저장되어 있는 형태
- 스크립트: 명령문들 모음

## 오라클 Live SQL 기본 사용법
### 쿼리 실행
- Worksheet: SQL 쿼리 작성 및 실행하는 공간
- 워크시트에 쿼리 작성 후 *Run Script* 버튼 클릭해 실행
  - 실행 결과: 아래 script output 또는 query output에서 확인
  - 실행 결과 로컬에 저장 가능(.csv, .json 등)

### 쿼리(sql파일, 스크립트) 저장
워크시트 위쪽 내비게이션 바에서 아래 과정 거쳐 파일 형태로 저장
- 현재 워크시트 파일명 클릭 -> Save as -> (원하는SQL파일명) 입력 / 저장장소: Database 지정 -> Save 클릭
- 저장된 SQL파일을 왼쪽 메뉴의 Files 탭에서 확인 가능, 우클릭 후 Open하면 워크시트에 불러올 수 있음
> 교수님 말씀으로는 세션 영역에 우리가 입력한 스크립트를 저장할 수 있다는데,
> 사이트가 개편돼서 그런지 찾지 못했음
